# Task 1 – Number Guessing Game 🎮

This is a console-based number guessing game developed during my internship at **Cognifyz Technologies**.

## 📌 Features
- Random number generator
- User guessing input
- Hints for too high or too low
- Success message with attempt count

## 🛠️ Technologies Used
- Java
- Maven
- IntelliJ IDEA

## 🚀 How to Run
1. Clone this repo or download the ZIP
2. Open it in IntelliJ
3. Run the `Game.java` file in the `src/com/cognifyz` package
